# Authentication

> **Route ownership boundary.** **Better Auth owns the identity endpoints** under
> `/api/v1/auth/*` (login, register, social, OTP, logout, sessions, verification).
> **FWorld owns business endpoints**, which must **never** be mounted inside Better
> Auth's route space. The authenticated **application user** is a FWorld concept,
> so it lives at **`GET /me`** (not `/auth/me`) — `/me` represents the app user,
> not the identity provider. Profile updates are likewise a FWorld endpoint
> outside `/auth/*`.

Identity (Better Auth, `/api/v1/auth/*`):

POST /auth/login

POST /auth/register

POST /auth/google

POST /auth/apple

POST /auth/otp/send

POST /auth/otp/verify

POST /auth/logout

Application user (FWorld, outside `/auth/*`):

GET /me

PUT /me
